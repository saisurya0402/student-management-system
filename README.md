# Student Management System

A console-based CRUD application for managing student records, built with Python and SQLite using OOP design principles.

## Features
- Add, view, update, and delete student records
- Search students by name
- Summary statistics by course
- SQLite persistence with unique email enforcement
- Clean OOP architecture (Model, Repository, CLI layers)

## Tech Stack
- **Python 3.x**
- **SQLite3** (built-in)

## How to Run

```bash
python student_management.py
```

No external dependencies required.

## Project Structure
```
student-management-system/
├── student_management.py   # Main application
├── students.db             # Auto-created SQLite database
└── README.md
```
